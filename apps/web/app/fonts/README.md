# ROAM typography

Outfit gives headings, navigation and map labels a rounded game character. DM Sans keeps forms, chat, travel details and longer text readable as an app.

Both variable fonts are self-hosted with `next/font/local`; the browser does not contact Google Fonts. The unmodified files came from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/outfit
- https://github.com/google/fonts/tree/main/ofl/dmsans

The accompanying SIL Open Font License files preserve the original copyright and redistribution terms.
